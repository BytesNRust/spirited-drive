# Security

The game reads files that players bring in (the CD's data, mods, imported tracks) and asks GitHub once at start
whether a newer release exists. If you find a way for a crafted file or answer to crash the game in a way that
could run code, or any other security problem, please report it **privately** through GitHub's
[security advisories](../../security/advisories/new) rather than a public issue.

Only the latest release is supported.
