# Track light files and the light editor

The light the port makes for a track with no PS1 disc (the made light) is kept as text files, one per track and time of day:
`data/track_light/<TRACK><A|B|C|N>.txt` (A dawn, B day, C dusk, N night). They are generated by `tools/export_track_light.sh`
with Restomod '26's settings and no disc; the PS1 disc's own light is never written (it is EA's and Sony's data).

## Which light the game uses

* The file's rows (the base) are read only when the port's settings are the ones the file was made with (the header's `banderas`).
  With others the light is made in code as before, and the log and the editor's second line say which settings differ.
* The retouches (`brillo`, `tono_tunel`) count either way: they go over the file's rows or over the code's.
* A mod can replace a file: `track_light_set_mod_dir` makes the lookup try `<mod>/track_light/<file>` first (the mods system does not call it yet).
* `TNFS_TRACK_LIGHT_FILE=0` ignores the files (the code's light only); `TNFS_EXPORT_TRACK_LIGHT=<dir>` writes the code's light as files.

## Format (a line a run of nodes, `#` starts a comment)

    pista CY1 hora N nodos 1920 banderas dff     the header
    filas 0 5 255 255 61 61 62 63 255 60 61 62 63    nodes 0..5 have this row of 11 points
    tunel 1064 1171        road tunnel nodes (also sala, coche_tenue, canon)
    pozo 13 13 1           a street lamp's pool, class 1..4 (also pozo_coche)
    coche_disco 1 <6 floats>   the car's ratios in a tunnel (hex floats)
    reparto neutro 0 ciudad 1
    tono_tunel noche 1.0 0.35 0.05 174    retouch: a warm tunnel's cast and its light in percent (dia: the day's)
    brillo 120 180 70                     retouch: nodes 120..180 at 70 percent of their light

## Light editor

`light_edit=1` in `port.cfg` (or `TNFS_LIGHT_EDIT=1` as a launcher) shows, in a race with a made light, the node the car is at, the file's state and the values there.
F10 holds the race where it is, F11 copies a `brillo N N 100` line to the clipboard. Saving the file reloads the light within a second, without leaving the race.
